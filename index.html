기본 워크플로
  1. 맵 구성 — 상단에서 프리셋을 적용하거나, 편집 도구로 직접 배치·연결합니다.
  2. 수요 설정 — 좌측 📦 수요 탭에서 배출 주기·변동(CV)을 입력합니다.
  3. 사양 입력 — 🚗 차량 / 🔋 에너지 탭에 실제 장비 스펙을 넣습니다.
  4. 실행·관찰 — 배속을 올려 정상상태까지 돌린 뒤 우측 📊 총괄의 진단을 확인합니다.
  5. 검증 — 🧪 실험실에서 스윕·몬테카를로로 통계적 신뢰도를 확보합니다.
  6. 의사결정 — 💰 경제성에서 회수기간을 확인하고 📑 리포트로 내보냅니다.

계산 모델 근거
  • 주행 — 사다리꼴 속도 프로파일: 거리가 짧으면 삼각 프로파일로 자동 전환
  • 혼잡 — Greenshields 밀도-속도 관계 + 교차점 간섭 보정
  • 포트 대기 — Erlang-C(M/M/c) 대기행렬로 해석 추정, 반복 수렴 적용
  • 배터리 — 소비전력(W) × 시간 ÷ 용량(kWh) 에너지 수지
  • 배차 — 헝가리안 O(n³) 전역 최적 할당
  • 묶음 적재 — Payload ≥ 2이면 같은 피킹대→같은 드롭 화물을 묶어 운반, 적재·하역 시간은 수량에 비례. 해석 모델은 "항상 가득 싣는다"는 상한 가정
